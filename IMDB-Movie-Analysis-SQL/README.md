# 🎬 IMDB Movie Analysis (SQL)

> Exploratory data analysis of the IMDB movie database using SQL to uncover trends in ratings, genres, directors, and box office performance.

---

## 📌 Problem Statement

The film industry generates billions of dollars annually, yet what makes a movie successful is not always obvious. This project uses SQL to analyze the IMDB dataset and answer business questions about genre performance, director success rates, rating distributions, and revenue trends.

---

## 📊 Dataset

| Detail | Info |
|--------|------|
| Source | IMDB Public Dataset |
| Tables | Movies, Ratings, Directors, Genres, Cast |
| Size | 80,000+ movie records |
| Analysis Type | Descriptive / Exploratory |

---

## 🧠 Key Questions Answered

- Which genres consistently receive the highest ratings?
- Who are the top-performing directors by average rating?
- How has average movie rating changed over the decades?
- What is the relationship between runtime and rating?
- Which years produced the most highly-rated films?

---

## 📈 Sample Findings

- Drama and Documentary genres average the highest ratings
- Movies between 90–120 minutes tend to score highest
- Ratings have shifted notably post-2000 due to voting volume changes
